# Automotive-ECU-Test-Data-Analysis-and-Validation-Using-Python
A Python project that manages and analyzes ECU test data using dictionaries and lists. It validates voltage and temperature ranges, calculates test pass percentages, determines ECU test status, and demonstrates adding, modifying, and deleting ECU records.

## Description
This project simulates ECU test result analysis using Python dictionaries and lists. It evaluates voltage, temperature, and test pass percentage to determine the overall status of each ECU.

## Features
- Store and manage multiple ECU test records
- Validate voltage and temperature ranges
- Calculate test pass percentages
- Determine ECU pass/fail status
- Add, update, and delete ECU records
- Display test results and ECU status

## Technologies
- Python 
- Dictionaries and Lists
- Loops and Conditional Statements
- Data Validation and Calculations

## Objective
To practice Python data structures and apply basic data analysis and validation concepts to automotive ECU testing.

## Note
This is a simulation using sample ECU data and illustrative validation limits. It does not test actual vehicle hardware.
